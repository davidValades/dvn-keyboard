# DVN-65 Phase 1 geometry artifacts

## G1R+ v5

Current working geometry candidate for Phase 1 physical validation.

Key characteristics:
- approximately 65% ISO-ES
- unibody semi-split
- 6° per half / 12° total opening
- conventional row stagger
- split Space for geometry testing
- physical arrow cluster retained
- Context Display at the upper edge of the right control area
- push rotary encoder below the display
- no dedicated physical context selector

These files are research artifacts, not final PCB or case dimensions.

## Printing

Print at **100% / Actual Size**. Do not use "Fit to page".

Verify the printed 100 mm reference bar with a ruler before evaluating posture or reach.

Files:
- `DVN65_G1Rplus_v5_A3_1to1.pdf` — single-sheet A3 template
- `DVN65_G1Rplus_v5_A4_Tiled_1to1.pdf` — tiled A4 template
